This submission contains the implementation and supporting materials developed for SP-2. The work focused on building and validating the constraint-based solution approach, documenting infeasible cases, and presenting the results in a form that can be more easily understood and demonstrated.

### Components Included

The submission includes the notebook containing the CSP implementation, JSON-based test instances representing feasible and infeasible scenarios, the written infeasibility explanation, and the website simulation/representation used to demonstrate the system.

The notebook serves as the primary computational implementation. The supporting JSON files provide structured inputs that allow the solver to be tested against different scenarios. The infeasibility documentation explains the conditions that prevent a valid assignment from being generated. The website representation complements these materials by providing a clearer visualization of the system's behavior.
